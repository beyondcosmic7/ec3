# ec3 — Eskort Creations

Bespoke Indian women's ethnic and fusion wear web atelier (Kurtas, 2-Piece/3-Piece sets, Longline Shrugs).
Unrushed cotton, measured in inches. Built with Next.js 16 App Router, Turbopack, and Tailwind CSS v4.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Quality Gates

- `pnpm test` — Run Vitest suite
- `pnpm typecheck` — Run TypeScript compiler check
- `pnpm slop:scan` — Run design & copy pattern scan
- `pnpm build` — Build production bundle
